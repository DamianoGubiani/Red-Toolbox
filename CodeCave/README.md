# CodeCave

A compact Python utility for identifying and leveraging code caves in executables.

## Features

- Scans binaries for unused memory regions suitable for code injection
- Reports cave addresses and sizes
- Minimal, script-based implementation for quick analysis

## Usage

1. Run the script against a target executable.
2. Review identified caves and their available sizes.
3. Use the output to guide safe code injection or patching.

## Requirements

- Python 3.x

## Disclaimer

Use responsibly and only on files you own or have permission to analyze.
